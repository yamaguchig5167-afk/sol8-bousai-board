# 防災ボード（MAXHUB 用・試作）

**案件区分：ソルエイト案件**（社内用メモ。お客様には渡さない）

MAXHUB に常時映しておく、事業所ごとの防災・BCP の表示画面。サーバーなし・月額のデータ費用なし。

## 画面

| 画面 | 中身 |
|---|---|
| いま | 警報の帯（気象庁のレベル色）・きょう/あすの天気・近くの観測所の気温と雨・雨雲・最近の地震・社内のライフライン |
| 地図 | 事業所の印＋洪水の浸水・土石流・がけ崩れ・地すべり（ハザードマップ）、雨雲、キキクル（土砂・浸水） |
| ライフライン | 電気・水道・ガス・道路・建物を「使える／一部だけ／使えない／確かめ中」で記録。インターネットは自動。公式ページの QR 6つ |
| もしものとき | すぐ〜1時間／1時間〜1日／1日〜3日の行動、集まる場所、連絡先、171 |
| 設定 | 事業所名・住所（市町村を自動で特定）・集まる場所・連絡先・自動切りかえ・訓練の表示 |

- さわらない時間が2分続くと、25秒ごとに画面を順番に切りかえる。
- 警報（レベル3以上）か、その市町村で震度4以上のときは、帯に「もしものときの行動を見る」が出る。画面を勝手に非常時へ切りかえることはしない（判断は会社側）。
- 通信が切れたら上の帯に出し、最後に取れた情報を残す。
- アドレスの末尾に `#drill` を付けると訓練の表示（見本の警報と地震）。
- 言葉は 日本語／繁體中文／English（上の帯のボタン。`?lang=zh`・`?lang=en` でも指定できる）。設定の画面は日本語のまま。訳は `i18n.mjs`。
- 「スマホで見る」で、この事業所の設定を入れたリンクの QR が出る。設定の画面の「この事業所のリンク」（`#s=…`）を別の端末で開くと、名前・住所・集まる場所・連絡先が入った状態で始まる。ライフラインの記録はリンクに入らない。

## 動かす

```
node serve.mjs      → http://localhost:3760/
node check.mjs      全画面を 1920×1080 とスマホ幅で撮り、qa/ に保存
node op-test.mjs    操作の試験（24項目）
PORT=3761 node serve.mjs ／ BOARD_URL=http://localhost:3761/ node check.mjs   番号と向き先を変えるとき
```

## 情報の出どころ（すべて画面から直接読む・鍵は不要）

- 気象庁ホームページ：警報・注意報（`warning/data/r8/`＝2026年5月からの新しい形式）、天気予報、アメダス、地震、雨雲（ナウキャスト）、キキクル
- 国土地理院：地理院タイル、住所検索
- ハザードマップポータルサイト：洪水の浸水（想定最大規模）、土砂災害警戒区域

## いまの版に無いもの

- 河川ごとの氾濫の情報（気象庁の配信が空のときしか確認できておらず、形式を確かめられなかった）
- 停電・断水・道路の自動取得（公開の配信が無いため、QR で公式ページへ案内）
- 津波・台風の進路
- 天気の文と地名の翻訳（繁體中文・English では天気を「晴・陰・雨・雪」の区分だけで出す。警報の英語名は気象庁ホームページの英語表示に合わせた。繁體中文の言い回しは公式の訳が無く、台湾の方の確認がまだ）
- 複数の端末でのライフライン記録の共有（いまは MAXHUB 1台の中だけ）
- MAXHUB 実機での確認、公開（どこにも公開していない）
